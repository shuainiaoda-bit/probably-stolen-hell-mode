# 这就是地狱吗？

《深空当铺：可能是偷的》地狱模式。同一个安装包适用于 Steam 默认公开版 Build 26525552（0.46D）和 `open_beta` Build 26772488（1.0.0.16）。

把 `ProbablyStolenHellMode` 文件夹放进游戏的 `Mods` 文件夹，在主菜单启用并重启。七项新增特质位于原版开局特质页第一排左侧，可用于所有难度。选完特质后照常选择难度。

### 手动安装

1. 在 [GitHub Releases](https://github.com/shuainiaoda-bit/probably-stolen-hell-mode/releases/latest) 下载 `ProbablyStolenHellMode-0.2.5.zip`。
2. 解压后将 `ProbablyStolenHellMode` 文件夹放入游戏的 `Mods`，确认 `manifest.xml` 位于该文件夹内。
3. 在游戏主菜单的 Mod 管理中启用，重启游戏并开始新存档。

## 地狱难度

要玩生存挑战，在难度页选中「赤字连连」后面的「这就是地狱吗？」。

- 基础房租 250 信用点。原版供货商加价 150%，其余难度规则沿用赤字连连。
- 开局有 2,000 kcal 食物储备和 1,000 mL 饮水储备。每次睡觉消耗 300 kcal 和 300 mL。食物归零会饿死，饮水归零会渴死，两项同时归零以渴死结算。
- 按住食物和饮水条可一起拖动，位置随存档保留。
- 右键自己拥有的物品，选择「进食」或「饮水」。饮水要求基础水或以上。瓶装水只扣实际补充的量。密封水配给包需要有空间喝下整包，也可以先倒进容器。
- 每周四开店后，下层区补给商会上门。食品包括营养果、碳酸代乳、代糖果汁、合成肉和速食拉面。小号密封水和标准密封水分别以 12 和 24 信用点为基础标价。

## 特质

| 特质 | 点数 | 效果 |
| --- | --- | --- |
| 周末不办公 | −1 | 第 7 天收第一期房租，从第 12 天开始改为每周五上门。 |
| 不准玩水商 | −2 | 店内水龙头禁用。 |
| 保单只认一栏 | −1 | 在夜间账单选择承保类别，本周首次投保后锁定。设备包括机器、模块和节点，贵重货按游戏的稀有、高端和奢侈品标签识别。 |
| 担保人已注销 | −3 | 王尔德网络里的新玩法入口停止出售。专精自带的服务、店面升级和普通人脉服务照常使用。 |
| 只收散户 | −1 | 固定卖家停止上门，包括周四补给商。散户买卖照常。 |
| 先扣房租 | −2 | 普通销售收入的 30% 自动预存，直到存满下一期房租。日历显示已存和待缴金额。 |
| 整箱价 | 0 | 柜台买入须购买卖家的全部库存，包含其余货页，并在原批发价上再打九折。夜间在杰克逊博士处可单买。与「只收散户」互斥。 |

难度、已选特质和地狱模式储备随本局保存。继续游玩使用了这些规则的存档时，请保持 Mod 启用。

在项目目录运行 `build.ps1` 可生成打包目录。使用 `-Game` 指定要引用的游戏目录。双分支安装包使用默认公开版的程序集编译。
